# Introducción a la Nube Pública (INP)

Apuntes del módulo optativo **Introducción a la Nube Pública**, de 2.º del ciclo formativo de grado superior de Desarrollo de Aplicaciones Web (DAW), en modalidad semipresencial. Curso 2026-2027.

**Web de los apuntes:** <https://fjavier-hernandez.github.io/cloud/>

## Contenido

- **Acceso:** cómo entrar en AWS Academy, en el laboratorio y en Skill Builder.
- **Temas 1 a 8:** fundamentos de la nube y AWS, seguridad e IAM, redes y entrega de contenido, cómputo y *serverless*, almacenamiento, bases de datos, arquitectura *Well-Architected*, y escalado y monitorización.
- **Guías de las prácticas y soluciones del Autocheck**, como apoyo al estudio.
- **Certificación:** preparación del examen AWS Certified Cloud Practitioner (CLF-C02).

Las entregas, los plazos y las calificaciones se gestionan en el aula virtual del centro (Aules).

## Compilar en local

El sitio está hecho con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

```bash
pip install "mkdocs-material[imaging]" mkdocs-print-site-plugin
mkdocs serve
```

Después, abre <http://127.0.0.1:8000> en el navegador.
